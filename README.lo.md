# RIPPCSX2

**ໂປຣແກຣມຈຳລອງ PlayStation 2 ສຳລັບທົດສອບ ແລະ ພັດທະນາ homebrew, ສ້າງມາໃຫ້ທ່ານ ຫຼື ຕົວແທນ AI ເປັນຜູ້ຄວບຄຸມ.**

RIPPCSX2 ແມ່ນ PCSX2 v2.9.96 ພ້ອມການປ່ຽນແປງທີ່ນັກພັດທະນາ homebrew ຂອງ PS2 ຕ້ອງການເພື່ອເຫັນຂອງແທ້: ໂໝດວິດີໂອ HD ຖືກສະແດງ, ບັນທຶກ ແລະ ຖ່າຍພາບໜ້າຈໍຄືກັບທີ່ໂທລະທັດ HD ສະແດງ, ແລະ ຈຸດຢຸດຂໍ້ມູນຮາດແວຂອງ EE, ເພື່ອໃຫ້ເມນູໃນເກມ ແລະ ເຄື່ອງມືໂໝດວິດີໂອທີ່ເກາະໃສ່ຣີຈິດສະເຕີ GS (GSM ຂອງ Open PS2 Loader, ເມນູໃນເກມຂອງ RIPPS2) ເຮັດວຽກຄືເທິງເຄື່ອງແທ້. ສ່ວນອື່ນທັງໝົດແມ່ນ PCSX2 ທຳມະດາ. ມັນເລີ່ມຕົ້ນເປັນຫ້ອງທົດລອງຂອງ front end [RIPPS2](https://github.com/akilluminati47/RIPPS2) ແລະ ແມ່ນສຳລັບທຸກຄົນທີ່ສ້າງ homebrew, ທີມ ຫຼື ເຄື່ອງມືສຳລັບ PS2.

**[ເບິ່ງເວັບໄຊ](https://akilluminati47.github.io/RIPPCSX2/)**: ແກະ PS2 ອອກ ຫຼື ລະເບີດມັນ, ທຸກຢ່າງກ່ຽວກັບ RIPPCSX2 ຢູ່ໃນແຜງ Info.

<a id="download-rippcsx2-windows-ziphttpsgithubcomakilluminati47rippcsx2releaseslatestdownloadrippcsx2-windows-x64-avx2zip"></a>

### [ດາວໂຫຼດ RIPPCSX2 (ໄຟລ໌ zip ສຳລັບ Windows)](https://github.com/akilluminati47/RIPPCSX2/releases/latest/download/RIPPCSX2-windows-x64-avx2.zip)

Windows 10 ຫຼື 11, x64, CPU ທີ່ຮອງຮັບ AVX2. ແຕກໄຟລ໌ໄວ້ບ່ອນໃດກໍໄດ້, ເປີດ `pcsx2-qtx64-avx2.exe` ແລະ ຊີ້ໄປຫາ BIOS ທີ່ທ່ານ dump ເອງ. ໄຟລ໌ zip ມີ `portable.txt` ຫວ່າງຢູ່ຂ້າງ exe, ສະນັ້ນ RIPPCSX2 ຈຶ່ງເກັບການຕັ້ງຄ່າ ແລະ ໄຟລ໌ທັງໝົດໄວ້ໃນໂຟນເດີຂອງມັນເອງ: PCSX2 ທີ່ທ່ານຕິດຕັ້ງໄວ້ແລ້ວຍັງຄົງການຕັ້ງຄ່າຂອງມັນ, ບໍ່ຖືກແຕະຕ້ອງ. ລຸ້ນເຜີຍແຜ່ແມ່ນລຸ້ນໃໝ່ລ່າສຸດສະເໝີ ([ໜ້າຂອງມັນ](https://github.com/akilluminati47/RIPPCSX2/releases/tag/rolling)); ຄລິບຂ້າງລຸ່ມຢູ່ໃນ [docs/videos](docs/videos).

**ເປີດໂປຣແກຣມ `.elf` ເພື່ອທົດສອບ:** System > Start File, ຫຼື `pcsx2-qtx64-avx2.exe -fastboot -elf <your.elf>`, ແລະ ໂປຣແກຣມຈະບູດຄືກັບທີ່ບູດຈາກບັດໜ່ວຍຄວາມຈຳ ຫຼື USB ເທິງ PS2. ມັນ **ເຮັດວຽກຄືຮາດແວແທ້**: ELF ທີ່ເປີດ ELF ອື່ນຈະມອບເຄື່ອງໃຫ້ແລ້ວຫາຍໄປ, ເມນູໃນເກມທີ່ເກາະໃສ່ GS ຈະແຕ້ມທັບເຟຣມແທ້ຂອງເກມ, ແລະ ການປິດເຄື່ອງຈະປິດ VM ຄືເຄື່ອງເກມທີ່ຖືກປິດໄຟ.

## ເບິ່ງມັນເຮັດວຽກ

ແຕ່ລະຄລິບແມ່ນການແລ່ນແທ້ໃນຫ້ອງທົດລອງເທິງລຸ້ນນີ້, ຕັດໃຫ້ສັ້ນກວ່າ 12 ວິນາທີ.

![Claude runs a RIPPS2 test in RIPPCSX2 on a hidden desktop, watched from the taskbar panel](docs/rippcsx2-ai-test.gif)

**ຕົວແທນ AI ກຳລັງທົດສອບ ELF.** ບັນທຶກຈາກມຸມລຸ່ມຂວາຂອງໜ້າຈໍຜູ້ໃຊ້ (ແຖບໜ້າວຽກ, ສ່ວນໜຶ່ງຂອງເຊດຊັນ Claude): Claude ເປີດ `RIPPS2.elf` ໃນ RIPPCSX2 ເທິງເດັສທັອບທີ່ເຊື່ອງໄວ້, ເປີດ Aqua Teen Hunger Force ຈາກອິມເມດ HDD ແລະ ເປີດເມນູໃນເກມຂອງ RIPPS2 ທັບມັນ. ແຜງນ້ອຍແມ່ນສິ່ງດຽວທີ່ຢູ່ເທິງໜ້າຈໍ; ແປ້ນພິມ ແລະ ເມົ້າຍັງຢູ່ກັບຜູ້ໃຊ້.

![RIPPS2's in-game menu in RIPPCSX2: achievements, resume, menu again, power off](docs/rippcsx2-igr-menu.gif)

**ເມນູໃນເກມ, ທຸກໜ້າທີ່.** L1+L2+R1+R2+SELECT+START ເທິງເກມທີ່ກຳລັງແລ່ນ: ACHIEVEMENTS, RESUME (ເກມສືບຕໍ່), ເມນູອີກຄັ້ງເທິງເຟຣມຕໍ່ມາ, ແລ້ວ POWER OFF ທີ່ປິດ VM. ເມນູຮູ້ວ່າຈະແຕ້ມທັບເຟຣມໃດ ເພາະ RIPPCSX2 ຈຳລອງຈຸດຢຸດການຂຽນຂໍ້ມູນຂອງ EE.

![RIPPS2 running a newer RIPPS2.elf from the memory card in RIPPCSX2](docs/rippcsx2-elf-launch.gif)

**ELF ເປີດ ELF, ຄື PS2 ແທ້.** Memory Files ຂອງ RIPPS2 ເປີດ ແລະ ແລ່ນ `mc0:/RIPPS2/RIPPS2.ELF` (ລຸ້ນໃໝ່ລ່າສຸດ, ສຳເນົາໄວ້ໃນບັດ). RIPPS2 ທີ່ກຳລັງແລ່ນມອບໃຫ້ແລ້ວຫາຍໄປ; ລຸ້ນໃໝ່ໂຫຼດຈາກບັດ ແລະ ບູດຈົນເຖິງລາຍການເກມ.

## ສິ່ງທີ່ທ່ານໄດ້ເມື່ອທຽບກັບ PCSX2 v2.9.96 ທຳມະດາ

- **ເມນູ RIPPCSX2** ລະຫວ່າງ Debug ແລະ Help: Run ELF ແລະ Run Last ELF, Lab Monitor ແບບສົດ, Test Steps, Compatibility Report, ສະວິດຂອງ fork ແລະ ໂຟນເດີທີ່ເກັບທຸກຢ່າງ.
- **ປຸ່ມແຖບໜ້າວຽກສຳລັບການແລ່ນແບບເຊື່ອງ.** PCSX2 ທີ່ເລີ່ມໃນໜ້າຈໍເຊື່ອງຈະວາງປຸ່ມໜຶ່ງໃສ່ແຖບໜ້າວຽກຂອງທ່ານ, ດັ່ງນັ້ນຕົວປະສົມສຽງ ຫຼື mod ສຽງຕໍ່ແອັບຈະເຂົ້າເຖິງມັນໄດ້ຄືກັບໂປຣແກຣມອື່ນ.
- **ໂໝດ HD ສະແດງຖືກຕ້ອງ.** 720p ແລະ 1080i ສະແດງເປັນ 16:9 (ຕົ້ນສະບັບແຕ້ມເປັນ 4:3), ໃນທຸກການຕັ້ງຄ່າອັດຕາສ່ວນຍົກເວັ້ນ Stretch.
- **ການບັນທຶກ ແລະ ພາບໜ້າຈໍ HD.** F11 ບັນທຶກ 720p ທີ່ 1280 x 720 ແລະ 1080i ທີ່ 1920 x 1080 (ຫຼື ຕົວຄູນເມື່ອຂະຫຍາຍ), ໝາຍເປັນ 16:9; F8 ບັນທຶກພາບໜ້າຈໍຂະໜາດດຽວກັນ. ຕົ້ນສະບັບໃຫ້ 640 x 480 ຫຼື ບັບເຟີດິບກວ້າງ 640.
- **ການປ່ຽນໂໝດລະຫວ່າງບັນທຶກ** ຈະສືບຕໍ່ໃນໄຟລ໌ໃໝ່ຂະໜາດໃໝ່ ແທນທີ່ຈະຖືກບີບເຂົ້າໄຟລ໌ທຳອິດ.
- **1080i ຢູ່ບ່ອນທີ່ຖືກຕ້ອງ.** ຕົ້ນສະບັບເລື່ອນພາບ 1080i ຂຶ້ນ 42 ແຖວ (ດ້ານເທິງຖືກຕັດ, ແຖບດຳດ້ານລຸ່ມ); RIPPCSX2 ເລີ່ມມັນທີ່ແຖວ 40 ຄືກັບຈັງຫວະເວລາຂອງເຄື່ອງເອງ.
- **ຈຸດຢຸດການຂຽນຂໍ້ມູນຂອງ EE** (ໃໝ່ໃນ rippcsx2.2). COP0 `$24` (`MTBPC`, `MTDAB`, `MTDABM` ...) ເຮັດວຽກ: ການຂຽນໃສ່ທີ່ຢູ່ທີ່ຖືກເຝົ້າເບິ່ງຈະເກີດຂໍ້ຍົກເວັ້ນດີບັກລະດັບ 2 ທີ່ `0x80000100` ກ່ອນມັນຈະເຮັດວຽກ, ທັງໃນຕົວແປ ແລະ ຕົວຄອມໄພລ໌ຄືນ. GSM ຂອງ OPL ແລະ ເມນູໃນເກມຂອງ RIPPS2 ຕ້ອງການມັນເພື່ອຮູ້ວ່າເກມກຳລັງສະແດງເຟຣມໃດ.
- **ແຖວບັນທຶກໂໝດວິດີໂອ.** ທຸກການປ່ຽນໂໝດຈະບັນທຶກຈັງຫວະການຊິງ ແລະ ຣີຈິດສະເຕີການສະແດງ (`RIPPCSX2: video mode ...` ໃນ `logs/emulog.txt`).
- **ບໍ່ມີການສະເໜີອັບເດດອັດຕະໂນມັດ.** ແທັກເຜີຍແຜ່ເຮັດໃຫ້ຕົວອັບເດດຂອງ PCSX2 ປິດຢູ່, ສະນັ້ນມັນຈະບໍ່ "ອັບເດດ" ທ່ານກັບໄປຫາຕົ້ນສະບັບ.
- ຄວາມລະອຽດມາດຕະຖານບໍ່ຖືກແຕະຕ້ອງ: ພາບໜ້າຈໍ 480i ຄືກັບຕົ້ນສະບັບທຸກໄບຕ໌. `HDTVOutput = false` ໃຕ້ `[EmuCore/GS]` ໃນ `inis/PCSX2.ini` ຈະເອົາພຶດຕິກຳ HD ຕົ້ນສະບັບກັບມາເພື່ອປຽບທຽບຄຽງກັນ.

<a id="what-it-is-for"></a>

## ໃຊ້ເຮັດຫຍັງ

- **ຜູ້ສ້າງທີມ** (Open PS2 Loader, RiptOPL, RIPPS2): ຕັດສິນທີມທີ່ 720p ແລະ 1080i ຄືທີ່ໂທລະທັດສະແດງ, ແລະ ສ້າງພາບຕົວຢ່າງຂະໜາດແທ້ ແລະ ວິດີໂອນຳຊົມ.
- **ນັກພັດທະນາ homebrew:** ທົດສອບ ELF ທີ່ປ່ຽນໂໝດວິດີໂອ, ເກາະໃສ່ GS ຫຼື ໃຊ້ຣີຈິດສະເຕີດີບັກຂອງ EE, ແລະ ອ່ານຣີຈິດສະເຕີການສະແດງທີ່ແນ່ນອນທີ່ໂໝດໜຶ່ງຕັ້ງໄວ້ໃນບັນທຶກ.
- **ເມນູໃນເກມ ແລະ ເຄື່ອງມື GS:** GSM ຂອງ OPL, ເມນູໃນເກມຂອງ RIPPS2 ແລະ ສິ່ງອື່ນໃດທີ່ສ້າງເທິງຈຸດຢຸດການຂຽນຂໍ້ມູນ ແລ່ນໄດ້ໃນໂປຣແກຣມຈຳລອງ, ບໍ່ແມ່ນແຕ່ເທິງຮາດແວເທົ່ານັ້ນ.
- **ການທົດສອບອັດຕະໂນມັດ ແລະ ດ້ວຍ AI:** ການແລ່ນດ້ວຍສະຄຣິບເທິງເດັສທັອບທີ່ເຊື່ອງໄວ້ ພ້ອມພາບໜ້າຈໍ, ການບັນທຶກ, ສະຖານະບັນທຶກ ແລະ ການອ່ານໜ່ວຍຄວາມຈຳຜ່ານ PINE, ໂດຍບໍ່ຍຶດຄອມພິວເຕີຂອງທ່ານ.

<a id="the-end-goal-the-whole-library"></a>

## ເປົ້າໝາຍສຸດທ້າຍ: ຫ້ອງສະໝຸດທັງໝົດ

ວຽກໃຫຍ່ທີ່ສຸດຂ້າງໜ້າແມ່ນການທົດສອບເກມ PS2 ຜ່ານເສັ້ນທາງໂຄດຂອງ Open PS2 Loader ເອງ, ຕາມແບບທີ່ເຄື່ອງເກມແລ່ນມັນ, ແລະ ຂຽນໄວ້ວ່າແຕ່ລະເກມຕ້ອງການຫຍັງ: ELF, KELF, ແອັບ homebrew ແລະ ເກມໃນ sandbox ຂອງ OPL, ໂດຍທົດລອງໂໝດຄວາມເຂົ້າກັນໄດ້ແບບອັດຕະໂນມັດ. ມື້ໜຶ່ງອາດມີຄົນໃຊ້ສິ່ງນີ້ເຮັດໃຫ້ຫ້ອງສະໝຸດທັງໝົດແລ່ນໄດ້. ນັ້ນແມ່ນເປົ້າໝາຍສຸດທ້າຍຂອງ RIPPCSX2.

Compatibility Report ແມ່ນກ້າວທຳອິດ: ຜົນຂອງເກມ, ໂໝດ OPL ທີ່ໃຊ້ ແລະ ສະຖານະຂອງເຄື່ອງ, ບັນທຶກໃນ `reports/` ເປັນໄຟລ໌ ແລະ ແຖວໜຶ່ງໃນ `compatibility.csv`.

<a id="for-ai-agents-llms-and-their-users"></a>

## ສຳລັບຕົວແທນ AI, LLM ແລະ ຜູ້ໃຊ້ຂອງພວກມັນ

ຄັງນີ້ຂຽນໄວ້ເພື່ອໃຫ້ຕົວແທນສາມາດຕັ້ງຄ່າໃຫ້ຜູ້ໃຊ້ໄດ້ຈາກລິ້ງຢ່າງດຽວ. ໃຫ້ `https://github.com/akilluminati47/RIPPCSX2` ແກ່ຜູ້ຊ່ວຍຂອງທ່ານ ແລະ ຂໍໃຫ້ມັນຕິດຕັ້ງ RIPPCSX2; ທຸກສິ່ງທີ່ມັນຕ້ອງການຢູ່ທີ່ນີ້:

1. **ເອົາລຸ້ນມາ:** `RIPPCSX2-windows-x64-avx2.zip` ຈາກລຸ້ນເຜີຍແຜ່ຕໍ່ເນື່ອງ ([ລິ້ງໂດຍກົງ](https://github.com/akilluminati47/RIPPCSX2/releases/latest/download/RIPPCSX2-windows-x64-avx2.zip), ຫຼື `gh release download rolling -R akilluminati47/RIPPCSX2 -p "*.zip"`). ແຕກໄຟລ໌ໃສ່ໂຟນເດີຂອງມັນເອງ; `portable.txt` ຢູ່ຂ້າງ exe ແລ້ວ, ສະນັ້ນມັນຈະບໍ່ແຕະການຕັ້ງຄ່າຂອງ PCSX2 ທີ່ຕິດຕັ້ງໄວ້ເລີຍ.
2. **BIOS:** ຜູ້ໃຊ້ສະໜອງ BIOS ທີ່ dump ຈາກເຄື່ອງຂອງເຂົາເອງ (ຢ່າດາວໂຫຼດເດັດຂາດ): ວາງໄວ້ໃນໂຟນເດີ `bios` ຂ້າງ exe (ຫຼື ຊີ້ `[Folders] Bios` ໃນ `inis/PCSX2.ini` ໄປຫາມັນ) ແລະ ເລືອກມັນໃນຕົວຊ່ວຍການເປີດຄັ້ງທຳອິດ (`[Filenames] BIOS`).
3. **ແລ່ນບາງຢ່າງ:** `pcsx2-qtx64-avx2.exe -fastboot -elf <homebrew.elf>`, ຫຼື `-- <game.iso>`. ການຕັ້ງຄ່າແມ່ນ INI ທຳມະດາໃນ `inis/PCSX2.ini`; ບັນທຶກໄປທີ່ `logs/emulog.txt` (`[Logging] EnableEEConsole = true` ເພີ່ມ printf ຂອງ EE).
4. **ຄວບຄຸມ ແລະ ສັງເກດ:** F8 ພາບໜ້າຈໍ (`snaps/`), F11 ບັນທຶກ (`videos/`), F1 ສະຖານະບັນທຶກ (`sstates/`), ແລະ PINE (`[EmuCore] EnablePINE`, `PINESlot`) ເພື່ອອ່ານ ແລະ ຂຽນໜ່ວຍຄວາມຈຳ PS2 ຈາກສະຄຣິບ.
5. **ທົດສອບໂດຍບໍ່ແຍ່ງໜ້າຈໍ:** [`ripps2-lab/`](ripps2-lab/README.md) ອະທິບາຍການຕິດຕັ້ງຫ້ອງທົດລອງ (`install-lab.ps1` ວາງລຸ້ນໜຶ່ງໃນໂຟນເດີພົກພາ ແລະ ເກັບບັດ, ການຕັ້ງຄ່າ ແລະ ການບັນທຶກຂອງມັນ), ແລະ `tools/dev/ps2bg.ps1` ໃນຄັງ RIPPS2 ແລ່ນລາຍການຂັ້ນຕອນ (ປຸ່ມ, ການລໍຖ້າ, ພາບໜ້າຈໍ, ການບັນທຶກ) ເທິງເດັສທັອບທີ່ເຊື່ອງໄວ້ ພ້ອມແຜງໃນແຖບໜ້າວຽກທີ່ຜູ້ໃຊ້ເບິ່ງ, ຢຸດ ຫຼື ຮັບຊ່ວງຕໍ່ໄດ້.

ສິ່ງທີ່ປ່ຽນ ແລະ ເປັນຫຍັງ, ທີລະໄຟລ໌: **[RIPPCSX2.md](RIPPCSX2.md)**. ຕົວແທນທີ່ເຮັດວຽກກັບໂຄດຂອງ fork ນີ້: ຢ່າເປີດ pull request, issue ຫຼື ຄຳເຫັນໃນໂຄງການ PCSX2 ເດັດຂາດ (`AGENTS.md` ຂອງມັນຫ້າມການປະກອບສ່ວນທີ່ AI ສ້າງ); RIPPCSX2 ຍັງຄົງເປັນ fork.

**ບໍ່ກ່ຽວຂ້ອງກັບທີມ PCSX2.** GPL-3.0 ຄື PCSX2. ລາຍງານບັນຫາ RIPPCSX2 ໄປທີ່ RIPPS2 ([issues](https://github.com/akilluminati47/RIPPS2/issues)), ຢ່າລາຍງານໄປທີ່ PCSX2. ຕໍ່ໄປນີ້ແມ່ນ README ຂອງ PCSX2 ເອງ.

<a id="project-details"></a>

## ລາຍລະອຽດໂຄງການ

PCSX2 ໄດ້ຮັບການພັດທະນາມາຫຼາຍກວ່າ 20 ປີ. ລຸ້ນເກົ່າແລ່ນໄດ້ພຽງເດໂມເກມສາທາລະນະບໍ່ເທົ່າໃດອັນ, ແຕ່ລຸ້ນໃໝ່ແລ່ນເກມສ່ວນໃຫຍ່ໄດ້ເຕັມຄວາມໄວ, ລວມທັງເກມດັງເຊັ່ນ Final Fantasy X ແລະ Devil May Cry 3. ເຂົ້າເບິ່ງ [ລາຍການຄວາມເຂົ້າກັນໄດ້ຂອງ PCSX2](https://pcsx2.net/compat/) ສຳລັບສະຖານະຄວາມເຂົ້າກັນໄດ້ຫຼ້າສຸດຂອງເກມ (ທົດສອບແລ້ວຫຼາຍກວ່າ 2500 ເກມ).

ຕົວຕິດຕັ້ງ ແລະ ໄບນາຣີຂອງລຸ້ນສະຖຽນ ແລະ ລຸ້ນ nightly ມີຢູ່ໃນ [ເວັບໄຊຂອງພວກເຮົາ](https://pcsx2.net/downloads/).

<a id="system-requirements"></a>

## ຄວາມຕ້ອງການຂອງລະບົບ

PCSX2 ຮອງຮັບ Windows, Linux ແລະ Mac. [ໜ້າເອກະສານການຕັ້ງຄ່າ](https://pcsx2.net/docs/setup/requirements) ມີລາຍລະອຽດເພີ່ມເຕີມກ່ຽວກັບຄວາມຕ້ອງການຊອບແວ ແລະ ຮາດແວ.

ກະລຸນາສັງເກດວ່າຕ້ອງມີ BIOS ທີ່ dump ຈາກເຄື່ອງ PS2 ທີ່ເປັນເຈົ້າຂອງຢ່າງຖືກກົດໝາຍຈຶ່ງຈະໃຊ້ໂປຣແກຣມຈຳລອງໄດ້. ສຳລັບຂໍ້ມູນເພີ່ມເຕີມ, ເຂົ້າເບິ່ງ [ໜ້ານີ້](https://pcsx2.net/docs/setup/bios/).
